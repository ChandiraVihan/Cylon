# Cylon ( cycle on )

## Task Types

- Script Execution - run ( .py and .sh scripts )
- Database Backup - dump and save a databse 
- File Backup - copy or archive files /  folders
- Email Notification - send an alert or report via email
- Log Cleanup - delete old log files
- System Health Check - check CPU, memory, disk usage
- Report Generation - generate and export a report
- File Transfer - move files between locations ( FTP, SCP )
- Service Restart - restart a system service or process
- API calls - send and HTTP request to an external endpoint

## Possible workflows

- Backup DB → Generate Report → Send Email Notification → Cleanup old files

- Health Check → IF success → Restart Service → Log result

- Run Script → Transfer Files → Generate Report → Send Email
